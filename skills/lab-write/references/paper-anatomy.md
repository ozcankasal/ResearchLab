# Paper anatomy

Follow the structure the field expects. Formal work uses a theorem–proof structure. Empirical studies in the sciences, medicine and social sciences use IMRaD (Introduction, Methods, Results, Discussion) and the reporting standard in the project's plan. Humanities papers are organised by argument. The venue's own template comes first in every case. The jobs below apply to all of them.

## What each part must do

| Part | Its job | Test |
|---|---|---|
| Title | Say the result or the object, not the topic area | A reader can tell what is new from the title alone |
| Abstract | Four moves: the problem, why it matters, what we show (refutable), what follows. State limits briefly | No claim appears that the body does not prove or compute |
| Introduction | Widom's five questions: the problem, why it matters, why it is hard, why it is unsolved, our approach and its limits. End with a contribution list that points to sections | Each contribution starts "We prove", "We show" or "We compute", never "We study" |
| What we do not claim | The limits a reader might otherwise assume we cross | Every strong word in the abstract survives it |
| Related work | Generous and exact credit, under each field's own names | The closest prior result is named, with the exact difference |
| Body | Intuition before detail, an example before the general case. Lemmas factored out. Statements self-contained | Each theorem can be read without the surrounding text |
| Figures and tables | Captions that stand alone; regenerated by script | Each caption says what is plotted, how many runs, and what the error bars are |
| Discussion | What the results mean, what remains open, the honest limits | No new claims appear here |
| Appendix: sources | What each citation is used for; which ones enter a proof | Every load-bearing citation is verified |
| Appendix: reproducibility | The commands, the seed, and the map from statements to tests | A stranger can regenerate every number |

## Notation rules

These follow Knuth's minicourse and Halmos.

- Define every symbol before its first use. Use one notation per object and one object per notation.
- Separate formulas with words. Never start a sentence with a symbol.
- Write logical connectives as words in prose: "implies", "for all".
- Avoid subscripted subscripts. Number the displays you refer to.
- Read a sentence with each formula replaced by "blah". It should still read as a sentence.
- Use no superlatives about the authors' own work.

## Process

- Write the outline from the data, theorems and figures, and revise it as the work changes. A good outline doubles as a plan for the research.
- Start writing early; writing finds the gaps.
- Give the paper one clear point, and say it in the first paragraph.
- Do not narrate the path of discovery.
- Ask two or three readers who have never seen the work to read it cold. Each person can read a paper for the first time only once.
